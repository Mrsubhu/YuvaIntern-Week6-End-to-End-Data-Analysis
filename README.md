# YuvaIntern Week 6 – End-to-End Data Analysis Project

## 📌 Project Overview

This project consolidates the work completed during the YuvaIntern Data Analytics Internship into an end-to-end data analysis project. It covers data exploration, data cleaning, visualization, statistical analysis, machine learning, and business recommendations using the Online Retail dataset.

The project aims to identify meaningful patterns in retail transactions and communicate findings through a structured analytical report.

## 🎯 Objectives

- Explore the dataset and understand its structure.
- Identify missing values, duplicate records, and data quality issues.
- Clean and prepare data for analysis.
- Visualize revenue trends and product performance.
- Apply statistical techniques to investigate relationships and patterns.
- Develop a machine learning model for quantity prediction.
- Summarize findings and provide actionable recommendations.

## 🔍 Project Workflow

### 1. Data Exploration
- Reviewed dataset dimensions and column names.
- Examined data types, missing values, and duplicate records.
- Investigated transaction dates and numerical variables.

### 2. Data Cleaning
- Examined missing descriptions and customer identifiers.
- Checked duplicate transactions and invalid quantity or price values.
- Prepared derived fields for transaction analysis.

### 3. Data Visualization
- Monthly revenue trend analysis.
- Top-selling product analysis.
- Quantity and revenue relationship visualization.
- Correlation heatmap.

### 4. Statistical Analysis
- Compared daily revenue across selected periods using a t-test.
- Examined quantity and revenue correlation.
- Investigated monthly cancellation patterns using a chi-square test.
- Applied regression to study the mathematical relationship between quantity, unit price, and revenue.

### 5. Machine Learning
- Prepared transaction data for predictive analysis.
- Built a Random Forest regression model.
- Used time-series cross-validation during hyperparameter tuning.
- Evaluated predictions using MAE, RMSE, and R².

**Note:** Predictive performance should be interpreted in the context of the dataset and validation approach. Statistical associations and regression relationships do not automatically imply causation.

## 💡 Business Value

The analysis can help retail businesses explore sales trends, understand product performance, monitor transaction data quality, and investigate factors associated with revenue and demand.

Recommendations should be finalized based on the verified analytical results rather than assumed patterns.
